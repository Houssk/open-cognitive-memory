# Roadmap

This roadmap is provisional. Milestones should be revised through public issues and community review.

## Phase 0 — Foundations
- [ ] Define the OCM scientific vocabulary.
- [ ] Review existing cognitive and AI memory models.
- [ ] Define the initial cognitive ontology.
- [ ] Formalize the Wake–Sleep–Dream lifecycle as a testable computational abstraction.
- [ ] Define research hypotheses and research questions.
- [ ] Establish contribution, review, and governance processes.

**Exit criteria:** terminology, scope, hypotheses, and research principles are documented and reviewed.

## Phase 1 — Data and evaluation design
- [ ] Define the open cognitive dataset specification.
- [ ] Design a free-association collection protocol.
- [ ] Define cognitive graph evaluation metrics.
- [ ] Design a controlled Human vs LLM association benchmark.
- [ ] Publish dataset cards and privacy requirements.

**Exit criteria:** protocols are sufficiently precise for independent implementation and ethical review.

## Phase 2 — Baselines and pilot studies
- [ ] Implement a basic association-graph baseline.
- [ ] Implement associative retrieval baselines.
- [ ] Run a small protocol pilot with appropriate consent and review.
- [ ] Establish annotation guidance and inter-annotator agreement measures.
- [ ] Publish limitations and reproducibility instructions.

**Exit criteria:** at least one end-to-end pilot is reproducible and its data governance is documented.

## Phase 3 — Memory lifecycle experiments
- [ ] Evaluate consolidation strategies.
- [ ] Evaluate retrieval and forgetting trade-offs.
- [ ] Compare graph, vector, episodic, and hybrid memory baselines.
- [ ] Evaluate continual updates and interference.

**Exit criteria:** benchmark results include baselines, ablations, uncertainty, and reproducibility material.

## Phase 4 — Community and extension
- [ ] Invite external research groups to replicate protocols.
- [ ] Add new datasets and benchmark tracks through review.
- [ ] Publish versioned releases and research summaries.
- [ ] Maintain governance and dataset review.

## Ongoing requirements
Privacy, consent, provenance, documentation, security, and reproducibility apply to every phase.
