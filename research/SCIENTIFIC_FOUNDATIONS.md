# Scientific Foundations

This document is an initial map of the research foundations OCM intends to review. It is not an exhaustive literature review and should be expanded with primary sources, evidence summaries, and competing interpretations.

## Core domains

### Human memory and cognition
Relevant areas include working memory, episodic memory, semantic memory, autobiographical memory, associative retrieval, schema formation, forgetting, and consolidation.

### Associative organization
Association can be studied through free-association tasks, semantic similarity, spreading activation models, graph structure, and temporal changes in response patterns. These methods measure different phenomena and should not be treated as interchangeable.

### Complementary learning systems
The complementary learning systems perspective proposes interacting learning systems with different properties, including rapid episodic learning and slower integration. OCM should examine how this perspective informs computational memory architectures without claiming a one-to-one biological mapping.

### Knowledge representation
Knowledge graphs, ontologies, typed relations, temporal graphs, uncertainty, and provenance offer tools for representing structured knowledge. The choice of representation should be evaluated against concrete tasks.

### Agent memory and continual learning
Current AI memory systems use combinations of context windows, retrieval, vector stores, structured stores, summaries, and model updates. OCM will compare retention, retrieval, update, and consolidation strategies under common evaluation tasks.

## Evidence discipline

For every reference, record:
- Full bibliographic metadata and stable identifier.
- Research question and population/system studied.
- Method and operational definitions.
- Main findings, including uncertainty.
- Limitations and replication status.
- Relevance to OCM and what it does not establish.

Do not cite a paper as support for a claim it did not test. Distinguish peer-reviewed findings, preprints, technical reports, vendor research, and project hypotheses.
