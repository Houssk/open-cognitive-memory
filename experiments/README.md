# Initial Experiment Portfolio

This page indexes proposed experiments. None of these experiments should be treated as completed, preregistered, or empirically validated until the relevant protocol and results are published.

## E01 — Free Association
**Question:** What information do structured free-association observations capture, and how reliable are they across sessions?
**Candidate measures:** response distributions, test–retest reliability, context sensitivity, annotation agreement.

## E02 — Cognitive Graph Evolution
**Question:** How do graph structures derived from repeated observations change over time?
**Candidate measures:** graph similarity, edge turnover, temporal stability, change detection, robustness to measurement noise.

## E03 — Memory Consolidation
**Question:** Do explicit consolidation strategies improve retrieval or consistency relative to append-only and retrieval-only baselines?
**Candidate measures:** retrieval quality, redundancy, contradiction rate, latency, storage cost.

## E04 — Human vs LLM Associations
**Question:** Which dimensions of association patterns differ between human participants and language models under controlled tasks?
**Candidate measures:** semantic distance, diversity, entropy, context sensitivity, repeatability.

## E05 — Knowledge Structuring and Provenance
**Question:** Does explicit provenance improve the auditability and reliability of structured knowledge?
**Candidate measures:** source attribution, error tracing, contradiction handling, abstention calibration.

## E06 — Associative Retrieval
**Question:** Do typed associative links improve retrieval over keyword, vector, and graph-free baselines?
**Candidate measures:** precision/recall, ranking quality, task success, latency, robustness.

## E07 — Forgetting and Memory Selection
**Question:** How do decay, deletion, summarization, and retention policies affect future retrieval and interference?
**Candidate measures:** retention curves, retrieval utility, false recall, storage cost, recovery after updates.

## E08 — Continual Learning
**Question:** How do memory update strategies balance new knowledge acquisition, retention, interference, and resource use?
**Candidate measures:** forward/backward interference, update latency, retention, task performance, compute and storage cost.

## Minimum experiment report

Each experiment report should include:
- Research question and hypotheses.
- Protocol and operational definitions.
- Dataset provenance and license.
- Sampling and exclusion criteria.
- Baselines and implementation details.
- Metrics and analysis plan.
- Results, uncertainty, and negative findings.
- Limitations and threats to validity.
- Reproduction instructions and code/version identifiers.
- Ethics and privacy considerations where applicable.
